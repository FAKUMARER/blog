## 树链剖分

### 重链剖分

一般用于维护 **路径信息**，与 **点分治** 不同的是

树剖更针对 **单条路径** 或说 **路径上的点** 的某些信息，如维护 **路径加路径权值和**

而 **点分治** 通常用于 **统计特殊路径**

我们也可以把 **树剖** 理解成一种 **把树拍平成序列** 的手段

树剖求出的 $Dfn$ 序，**一段区间是一条路径**，而一般的 $DFS$ 序，**一段区间是一棵子树**

多数情况下，拍平之后会和 **线段树** 一起使用

感觉一到 **树链剖分 + 线段树**，码量就大起来了...

<br/>

#### [<font color = "#9d3dcf">Luogu P4211 [LNOI2014] LCA</font>](https://www.luogu.com.cn/problem/P4211)

给定一棵树，$Q$ 次询问，**每次询问** 给出区间 $[L, R]$ 和 一个点 $u$，求 $\sum _ {i = L} ^ R{Dep_{LCA(i, u)}}$

注意到一个点 **深度** 即为 **从根到那个点的路径长**

考虑对于一次询问，容易发现我们对于所有点 $i \in [L, R]$，从 $i$ 到根 路径加 $1$

然后只需要求 **从 $u$ 到根的路径和** 即为答案

> 显然，对于一个点 $i$，**从 $i$ 到根路径** 与 **从 $u$ 到根路径** 的 **交** 恰为 **从 $LCA$ 到根的路径**

**路径加路径求和**，可以 **树剖 + 线段树** 维护，于是 单次询问现在可以 $O(N \log ^ 2 N)$ 解决

可惜我们有 $Q$ 次询问啊，令人难受

但是看到每次询问 **一个区间信息**，而且容易发现这个信息是 **可差分的**

于是把每次询问区间 $[L, R]$ 转化成区间 $[1, R]$ 减去 $[1, L - 1]$

现在我们 **记录每个询问** 的 $L - 1, R$，然后 **扫描线** 依次加入 $1 \sim N$

> 加入 $i$ ：对 **从 $i$ 到根** 做 **路径加**

扫到一个询问的 $L_i - 1$ 时，查询 **从 $u_i$ 到根** 的 **路径和**，答案 **减去这部分贡献**

扫到一个询问的 $R_i$ 时，查询 **从 $u_i$ 到根** 的 **路径和**，答案 **加上这部分贡献**

> 代码长，但细节不多，注意 **取模**，然后 **点是从 $0$ 开始的就行**

```cpp
#include <bits/stdc++.h>

const int MAXN = 50005;

using namespace std;

struct Edge {
	int to, nxt;
} E[MAXN << 1];

int F[MAXN], H[MAXN], tot;

inline void Add_Edge (const int u, const int v) {
	E[++ tot] = {v, H[u]}, H[u] = tot;
}

namespace Tree_Cut {
	int Siz[MAXN], Dep[MAXN], Son[MAXN], Top[MAXN];
	int Ldf[MAXN], Rdf[MAXN], Idf[MAXN], Cnt;
	
	inline void DFS1 (const int x, const int f) {
		Dep[x] = Dep[f] + 1, F[x] = f, Siz[x] = 1;
		for (int i = H[x]; i; i = E[i].nxt) {
			DFS1 (E[i].to, x), Siz[x] += Siz[E[i].to];
			Siz[E[i].to] > Siz[Son[x]] ? Son[x] = E[i].to : 0;
		}
	}
	
	inline void DFS2 (const int x, const int top) {
		Top[x] = top, Ldf[x] = ++ Cnt, Idf[Cnt] = x;
		if (Son[x]) DFS2 (Son[x], top);
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != Son[x]) DFS2 (E[i].to, E[i].to);
		Rdf[x] = Cnt;
	}
}

namespace SegTree {
	struct Node {
		int L, R;
		int Val, Tag;
	} T[MAXN << 2];
	
	#define LC (x << 1)
	#define RC (x << 1 | 1)
	#define M ((T[x].L + T[x].R) >> 1)
	
	inline void Maintain (const int x) {
		T[x].Val = T[LC].Val + T[RC].Val;
	}
	
	inline void PushAdd (const int x, const int v) {
		T[x].Tag += v, T[x].Val += 1ll * (T[x].R - T[x].L + 1) * v;
	}
	
	inline void Update (const int x) {
		if (T[x].Tag) 
			PushAdd (LC, T[x].Tag), PushAdd (RC, T[x].Tag), T[x].Tag = 0;
	}
	
	inline void Build (const int L, const int R, const int x = 1) {
		T[x].L = L, T[x].R = R;
		if (L == R) return ;
		Build (L, M, LC), Build (M + 1, R, RC), Maintain (x);
	}
	
	inline void Add (const int L, const int R, const int v, const int x = 1) {
		if (T[x].L > R || T[x].R < L) return ;
		if (L <= T[x].L && T[x].R <= R) return PushAdd (x, v);
		Update (x), Add (L, R, v, LC), Add (L, R, v, RC), Maintain (x);
	}
	
	inline int Sum (const int L, const int R, const int x = 1) {
		if (T[x].L > R || T[x].R < L) return 0;
		if (L <= T[x].L && T[x].R <= R) return T[x].Val;
		Update (x);
		return Sum (L, R, LC) + Sum (L, R, RC);
	}
	
	#undef M
}

inline void Add (int x) {
	using namespace Tree_Cut;
	while (x) SegTree::Add (Ldf[Top[x]], Ldf[x], 1), x = F[Top[x]];
}

inline int Sum (int x) {
	using namespace Tree_Cut;
	int Ret = 0;
	while (x) Ret += SegTree::Sum (Ldf[Top[x]], Ldf[x]), x = F[Top[x]];
	return Ret;
}

vector <int> St[MAXN], Ed[MAXN];
int Ans[MAXN];
int Que[MAXN];
int N, Q;

inline void Solve () {
	for (int i = 1; i <= N; ++ i) {
		Add (i);
		for (auto k : St[i]) Ans[k] -= Sum (Que[k]);
		for (auto k : Ed[i]) Ans[k] += Sum (Que[k]);
	}
}

int u, v, w, f;

int main () {
	
	ios::sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	
	cin >> N >> Q;
	
	for (int i = 2; i <= N; ++ i)
		cin >> f, Add_Edge (f + 1, i);
	
	Tree_Cut::DFS1 (1, 0), Tree_Cut::DFS2 (1, 1), SegTree::Build (1, N);
	
	for (int i = 1; i <= Q; ++ i)
		cin >> u >> v >> w, Que[i] = w + 1, St[u].push_back (i), Ed[v + 1].push_back (i);
	
	Solve ();
	
	for (int i = 1; i <= Q; ++ i) cout << Ans[i] % 201314 << '\n';
	
	return 0;
}
```

#### [<font color = "#9d3dcf">Luogu P5354 [Ynoi2017] 由乃的 OJ</font>](https://www.luogu.com.cn/problem/P5354)

**[<font color = "#52c41a">NOI2014 起床困难综合症</font>](https://www.luogu.com.cn/problem/P2114)** 的 **树上加强版**

给定一棵树，每个节点有一个 **操作** 和 **权值**，操作是 `&`，`|`，`^` 中的 **一种**

每次 **经过节点** 就把 **当前值** 操作上 **节点权值**

每次 **询问** 一个 **有向路径**，限定 **初始值范围**，求 走完整个路径后 **权值可能的最大值**

每次 **修改** 一个 **单点**，同时修改 **操作** 和 **权值**

<br/>

还挺有趣的一个题

树上路径询问，可以尝试 套路 **树剖 + 线段树** 维护

于是转化成 **序列上的问题** 如何用 **线段树** 维护

由于最后要求 **最大值**，而路径上的操作均为 **按位运算**，也就是 **不同位不相互影响**

可以想到 **贪心** 的大体思路，也即 想要让 **每一位尽量为 $1$**

容易想到去维护 **每一位** 最开始为 $0 / 1$，则其 **经过这个区间后会变成什么**

显然，若初始为 $0$，结束为 $1$，那么这一位 **一定会贡献到最大值里**

而若 初始为 $1$ 时，我们就需要考虑 **初始值范围** 这个限制，**从高位向低位贪心** 即可

最后只需要考虑这个信息 **怎么合并**，设存在 左右节点 $L, R$，需要合并成 $X$

显然 若 $X_0 = 1$ 则 $L_0 = 1 \& R_1 = 1$ 或 $L_0 = 0 \& R_0 = 1$

反之 则 $X_0 = 0$，于是有 $X_0 = (L_0 \& R_1) | (!L_0 \& R_0)$

同理 若 $X_1 = 1$ 则 $L_1 = 1 \& R_1 = 1$ 或 $L_1 = 0 \& R_0 = 1$

反之 则 $X_1 = 0$，于是有 $X_1 = (L_1 \& R_1) | (!L_1 \& R_0)$

由于最后是 **树上问题**，走的是 **有向路径**，会发现 $u \to LCA$ 与 $LCA \to v$

**两段路径** 在 $Dfn$  序方向上实际上是 **相反的**，而显然 **这个信息的合并有方向性**

于是线段树上需要 **额外维护** 反着走对应的 **两个信息**

于是现在 **单点修改**，区间询问 $\to$ **树剖 + 线段树**，大体是没问题了，但是 **过不了**

容易证明每次询问操作了 $\log ^ 2 N$ 个 **线段树节点**，不幸的是 **信息的合并** 需要 $\log V$ 的时间

于是时间复杂度来到了 $O ( N \log ^ 2 N \log V)$ 死得很惨

显然 **树剖 + 线段树** 这部分 **不好优化**，于是只能尝试把 **信息合并** 降到 $O(1)$

既然 **每一位都不互相干扰**，可以考虑 **放到一起维护**，于是使用 `unsigned long long`

每个线段树节点存储 $4$ 个 `unsigned long long`，合并时进行对应 **位运算** 即可

这样就省去了 **枚举每一位** 进行运算的时间，干掉一个 $\log V$，赢！

<br/>

```cpp
#include <bits/stdc++.h>

const int MAXN = 100005;

using namespace std;

struct Edge {
	int to, nxt;
} E[MAXN << 1];

int F[MAXN], H[MAXN], tot;

inline void Add_Edge (const int u, const int v) {
	E[++ tot] = {v, H[u]}, H[u] = tot;
	E[++ tot] = {u, H[v]}, H[v] = tot;
}

int Opt[MAXN];
unsigned long long Val[MAXN];

namespace Tree_Cut {
	int Siz[MAXN], Son[MAXN], Dep[MAXN], Top[MAXN];
	int Ldf[MAXN], Rdf[MAXN], Idf[MAXN], Cnt;
	
	inline void DFS1 (const int x, const int f) {
		Siz[x] = 1, Dep[x] = Dep[f] + 1, F[x] = f;
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != f)
				DFS1 (E[i].to, x), Siz[x] += Siz[E[i].to], Siz[E[i].to] > Siz[Son[x]] ? Son[x] = E[i].to : 0;
	}
	
	inline void DFS2 (const int x, const int top) {
		Ldf[x] = ++ Cnt, Idf[Cnt] = x, Top[x] = top;
		if (Son[x]) DFS2 (Son[x], top);
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != F[x] && E[i].to != Son[x])
				DFS2 (E[i].to, E[i].to);
		Rdf[x] = Cnt;
	}
	
	inline int LCA (int x, int y) {
		if (Dep[x] < Dep[y]) swap (x, y);
		while (Top[x] != Top[y])
			Dep[Top[x]] > Dep[Top[y]] ? x = F[Top[x]] : y = F[Top[y]];
		return Dep[x] > Dep[y] ? y : x;
	}
}

namespace SegTree {
	struct Node {
		int L = 0, R = 0;
		unsigned long long F[2], G[2];
	} T[MAXN << 2];
	
	inline Node Add (const Node &a, const Node &b) {
		Node c; c.L = min (a.L, b.L), c.R = max (a.R, b.R);
		c.F[0] = ((a.F[0] & b.F[1]) | ((~ a.F[0]) & b.F[0]));
		c.F[1] = ((a.F[1] & b.F[1]) | ((~ a.F[1]) & b.F[0]));
		c.G[0] = ((b.G[0] & a.G[1]) | ((~ b.G[0]) & a.G[0]));
		c.G[1] = ((b.G[1] & a.G[1]) | ((~ b.G[1]) & a.G[0]));
		return c;
	}
	
	#define LC (x << 1)
	#define RC (x << 1 | 1)
	#define M ((T[x].L + T[x].R) >> 1)
	
	inline void Maintain (const int x) {
		T[x] = Add (T[LC], T[RC]);
	}
	
	inline void Change (const int x) {
		int p = Tree_Cut::Idf[T[x].L];
		if (Opt[p] == 1) T[x].G[0] = T[x].F[0] = 0 & Val[p], T[x].G[1] = T[x].F[1] = (0ull - 1ull) & Val[p];
		if (Opt[p] == 2) T[x].G[0] = T[x].F[0] = 0 | Val[p], T[x].G[1] = T[x].F[1] = (0ull - 1ull) | Val[p];
		if (Opt[p] == 3) T[x].G[0] = T[x].F[0] = 0 ^ Val[p], T[x].G[1] = T[x].F[1] = (0ull - 1ull) ^ Val[p];
	}
	
	inline void Build (const int L, const int R, const int x = 1) {
		T[x].L = L, T[x].R = R;
		if (L == R) return Change (x);
		Build (L, M, LC), Build (M + 1, R, RC), Maintain (x);
	}
	
	inline void Modify (const int p, const int x = 1) {
		if (T[x].L == T[x].R) return Change (x);
		if (p <= M) return Modify (p, LC), Maintain (x);
		else return Modify (p, RC), Maintain (x);
	}
	
	inline Node Query (const int L, const int R, const int x = 1) {
		if (L <= T[x].L && T[x].R <= R) return T[x];
		if (L <= M && R <= M) return Query (L, R, LC);
		if (M <  L && M <  R) return Query (L, R, RC);
		if (L <= M && M <  R) return Add (Query (L, R, LC), Query (L, R, RC));
		return T[0];
	}
	
	#undef M 
}

int N, Q, K;
int u, v;
int opt, x, y;
unsigned long long z;

inline void Modify (const int x, const int o, const unsigned long long v) {
	Opt[x] = o, Val[x] = v;
	SegTree::Modify (Tree_Cut::Ldf[x]);
}

inline unsigned long long Query (int x, int y, unsigned long long lim) {
	using namespace Tree_Cut;
	
	unsigned long long Ret = 0;
	
	int lca = LCA (x, y);

	SegTree::Node p, q;
	while (Top[x] != Top[lca]) {
		if (!p.R) p = SegTree::Query (Ldf[Top[x]], Ldf[x]);
		else p = SegTree::Add (SegTree::Query (Ldf[Top[x]], Ldf[x]), p);
		x = F[Top[x]];
	}
	
	if (!p.R) p = SegTree::Query (Ldf[lca], Ldf[x]);
	else p = SegTree::Add (SegTree::Query (Ldf[lca], Ldf[x]), p);
	
	swap (p.F, p.G);
	
	while (Top[y] != Top[lca]) {
		if (!q.R) q = SegTree::Query (Ldf[Top[y]], Ldf[y]);
		else q = SegTree::Add (SegTree::Query (Ldf[Top[y]], Ldf[y]), q);
		y = F[Top[y]];
	}

	if (y != lca) {
		if (!q.R) q = SegTree::Query (Ldf[lca] + 1, Ldf[y]);
		else q = SegTree::Add (SegTree::Query (Ldf[lca] + 1, Ldf[y]), q);
	}
	
	if (q.R) p = Add (p, q);
		
	for (int i = 63; i >= 0; -- i) {
		if (p.F[0] & (1ull << i)) Ret += 1ull << i;
		else if ((p.F[1] & (1ull << i)) && (lim >= (1ull << i))) Ret += 1ull << i, lim -= (1ull << i);
	}
	
	return Ret;
} 

int main () {
	
	ios::sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	
	cin >> N >> Q >> K;
	
	for (int i = 1; i <= N; ++ i) cin >> Opt[i] >> Val[i];
	
	for (int i = 2; i <= N; ++ i) cin >> u >> v, Add_Edge (u, v);
	
	Tree_Cut::DFS1 (1, 0), Tree_Cut::DFS2 (1, 1), SegTree::Build (1, N);
	
	for (int i = 1; i <= Q; ++ i) {
		cin >> opt >> x >> y >> z;
		if (opt == 1) cout << Query  (x, y, z) << '\n';
		if (opt == 2) Modify (x, y, z);
	}
	
	return 0;
}
```

#### [<font color = "#0e1d69">CF757G Can Bash Save the Day?</font>](https://www.luogu.com.cn/problem/CF757G)

断断续续做了好几天，感觉前面做了后面就忘了

给出一棵 $N$ 个点的 **带权树** 和一个排列 $P_i$，支持两种操作，强制在线

1. 给定 $l, r, x$，询问 $\sum \limits_{i = l} ^ r Dis (P_i, x)$。

2. 给定 $x$，交换 $P_x, P_{x + 1}$。

<br/>

**重链剖分 + 主席树** 做法，这种 **路径信息询问** 大多可以使用这样的组合维护

要不就是 另外一种题解的 **边分树**（动态树分治，好像是 **标算**）

这个题中的距离式长得就很像 $P4211$ 里的东西，容易想到把它转化成 **两前缀相减**

即 $\sum \limits_{i = 1} ^ r - \sum \limits _ {i = 1} ^ l$ 的形式，于是我们只需要求 $\sum \limits_{i = 1} ^ k Dis (P_i, x)$ 即可，把它拆一下

$Dis(P_i, x) = Dep _ {P_i} + Dep_x - 2 Dep_{LCA}$，加上 $\sum$

于是 $\sum \limits_{i = 1} ^ k Dis (P_i, x) = (\sum \limits _ {i = 1} ^ k Dep_{P_i}) + k Dep_x - 2 (\sum \limits _{i = 1} ^ k Dep_{LCA (P_i, x)})$

显然第一部分 **维护一个前缀和** 即可，单点交换 **不影响后续值**，复杂度没有问题

第二部分是常量，询问的时候 **直接加上** 就行，更是唐诗

重点在于 **第三部分**，它真的和 $P4211$ 里的式子 **如出一辙**，考虑用 **同样方式计算**

也就是求 **到根的路径的并**，我们对 根到 $P_1 \sim P_k$ 这 $k$ 条路径做 **路径加 $1$**

然后求 **根到 $x$ 的路径权值和** 即是答案

$P4211$ 那个题也说了，这样的话单次询问的复杂度就是 $O(N \log ^ 2 N)$ 的，**不可接受**

而 $P4211$ 那个题可以 **离线扫描线** 计算贡献，可这个题 **强制在线**，令人难受

显然我们每次会在 **不同版本的树上** 查询，想到用 **主席树** 维护（$P4211$ 只用 **线段树** 就行）

**第 $i$ 个版本** 代表 对 **根到$P_1 \sim P_i$ 的 $i$ 条路径** 路径加后的结果

由于需要 **区间加** 操作，需要用到 **标记永久化** 的技巧，此处 **不多赘述**

这样每次查询只需要在 **对应版本的树** 上做 **路径和** 即可

**单点修改** 同样只需要把 **交换的两个点** 拿出来，重新插一下即可，**对后面无影响**

思路到这里就结束了，但是又过不了题... 这玩意儿 **空间被卡了**，火大！

考虑如下两个优化

1. 显然每次 **路径加** 会涉及 $\log N$ 次 **主席树** 上的 修改，会建出 $\log ^ 2$ 个 **新的点** 

​	但容易发现，每次修改只相当于 **一个版本**，没必要 **建这么多点**

​	于是每次 **路径加** 前 记录 **当前主席树上点数**

​	判断，当修改涉及到 **当前版本新建的点时**，直接在点上修改而非再新建节点

```cpp
inline void Add (const int rt, int x) {
	Lim = Tot; // 这里记录
	while (x) RT[rt] = Ins (Ldf[Top[x]], Ldf[x], RT[rt]), x = F[Top[x]];
}
```

```cpp
inline int Ins (const int l, const int r, unsigned long long x, const int L = 1, const int R = N) {
    if (x <= Lim) x = NewNode (x); // 这里判断
    if (l <= L && R <= r) return T[x].t ++ , T[x].v += (Pre[R] - Pre[L - 1]), x;
    if (l <= M) LC = Ins (l, r, LC, L, M);
    if (r >  M) RC = Ins (l, r, RC, M + 1, R);
    T[x].v = T[LC].v + T[RC].v + (Pre[R] - Pre[L - 1]) * T[x].t;
    return x;
}
```

<br/>

2. 在修改的过程中，**主席树上不可避免地会产生一些废点**，即 **不会被访问到的点**，浪费空间

​	但是由于其 **不易直接回收**，于是考虑 **定期暴力重构整棵树** 即可


```cpp
#include <bits/stdc++.h>

const int MAXN = 200005;
const int LOGN = 150;

using namespace std;

struct Edge {
	int to, nxt, w;
} E[MAXN << 1];

int F[MAXN], H[MAXN], tot;
int Val[MAXN];
long long Dep[MAXN], Sdp[MAXN], Pre[MAXN];

inline void Add_Edge (const int u, const int v, const int w) {
	E[++ tot] = {v, H[u], w}, H[u] = tot;
	E[++ tot] = {u, H[v], w}, H[v] = tot;
}

namespace Tree_Cut {
	int Siz[MAXN], Son[MAXN], Top[MAXN], Dis[MAXN];
	int Ldf[MAXN], Rdf[MAXN], Idf[MAXN], Cnt;
	
	inline void DFS1 (const int x, const int f, const long long dep = 0) {
		Siz[x] = 1, F[x] = f, Dep[x] = dep;
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != f) {
				DFS1 (E[i].to, x, dep + E[i].w), Dis[E[i].to] = E[i].w;
				Siz[x] += Siz[E[i].to], Siz[E[i].to] > Siz[Son[x]] ? Son[x] = E[i].to : 0;
			}
	}
	
	inline void DFS2 (const int x, const int top) {
		Top[x] = top, Ldf[x] = ++ Cnt, Idf[Cnt] = x;
		if (Son[x]) DFS2 (Son[x], top);
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != F[x] && E[i].to != Son[x])
				DFS2 (E[i].to, E[i].to);
		Rdf[x] = Cnt;
	}
}

int N, Q;

namespace PSDTree {
	struct Node {
		int lc, rc, t;
		long long v;
	} T[MAXN * LOGN];
	
	int RT[MAXN], Tot;
	unsigned long long Lim;
	
	#define LC T[x].lc
	#define RC T[x].rc
	#define M ((L + R) >> 1)
	
	inline int NewNode (const int x) {
		return T[++ Tot] = T[x], Tot;
	}
	
	inline int Ins (const int l, const int r, unsigned long long x, const int L = 1, const int R = N) {
		if (x <= Lim) x = NewNode (x);
		if (l <= L && R <= r) return T[x].t ++ , T[x].v += (Pre[R] - Pre[L - 1]), x;
		if (l <= M) LC = Ins (l, r, LC, L, M);
		if (r >  M) RC = Ins (l, r, RC, M + 1, R);
		T[x].v = T[LC].v + T[RC].v + (Pre[R] - Pre[L - 1]) * T[x].t;
		return x;
	}
	
	inline long long Sum (const int l, const int r, const int x, const int tag = 0, const int L = 1, const int R = N) {
		if (!x) return (Pre[min (R, r)] - Pre[max (L, l) - 1]) * tag;
		if (l <= L && R <= r) return T[x].v + 1ll * tag * (Pre[R] - Pre[L - 1]);
		long long Ret = 0;
		if (l <= M) Ret += Sum (l, r, LC, tag + T[x].t, L, M);
		if (r >  M) Ret += Sum (l, r, RC, tag + T[x].t, M + 1, R);
		return Ret;
	}
	
	#undef M
}

inline void Add (const int rt, int x) {
	using namespace PSDTree;
	using namespace Tree_Cut;
	Lim = Tot;
	while (x) RT[rt] = Ins (Ldf[Top[x]], Ldf[x], RT[rt]), x = F[Top[x]];
}

inline long long Sum (const int rt, int x) {
	using namespace PSDTree;
	using namespace Tree_Cut;
	long long Ret = Sdp[rt] + Dep[x] * rt;
	while (x) Ret -= 2ll * Sum (Ldf[Top[x]], Ldf[x], RT[rt]), x = F[Top[x]];
	return Ret;
}

inline void Build () {
	using namespace PSDTree;
	Tot = 0;
	for (int i = 1; i <= N; ++ i) RT[i] = RT[i - 1], Add (i, Val[i]);
}

int Opt, u, v, w;
long long Ans;

int main () {
	
	ios::sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	
	cin >> N >> Q;
	
	for (int i = 1; i <= N; ++ i) cin >> Val[i];
		
	for (int i = 2; i <= N; ++ i)
		cin >> u >> v >> w, Add_Edge (u, v, w);
	
	Tree_Cut::DFS1 (1, 0), Tree_Cut::DFS2 (1, 1);
	
	for (int i = 1; i <= N; ++ i) Pre[i] = Pre[i - 1] + Tree_Cut::Dis[Tree_Cut::Idf[i]];
	
	for (int i = 1; i <= N; ++ i) Sdp[i] = Sdp[i - 1] + Dep[Val[i]];
	
	Build ();
	
	for (int i = 1; i <= Q; ++ i) {
		cin >> Opt;
		if (i % 100001 == 0) Build ();
		if (Opt == 1) {
			cin >> u >> v >> w;
			u ^= Ans, v ^= Ans, w ^= Ans;
			
			cout << (Ans = Sum (v, w) - Sum (u - 1, w)) << '\n';
			
			Ans = Ans % (1 << 30);
		} else {
			cin >> u, u ^= Ans;
			Sdp[u] = Sdp[u - 1] + Dep[Val[u + 1]];
			PSDTree::RT[u] = PSDTree::RT[u - 1];
			Add (u, Val[u + 1]), swap (Val[u], Val[u + 1]);
		}
	}
	
	return 0;
}
```

#### [<font color = "#9d3dcf">CF696E ...Wait for it...</font>](https://www.luogu.com.cn/problem/CF696E)

细节牛牛题

看到每次删除 $k$ 个东西，**很吓人**

仔细一想发现是假的，因为一共只有 $M$ 个物品，**删完就没了**

所以我们只需要考虑怎么维护 **删一个物品** 的操作就行了，删 $k$ 个就 操作 $k$ 次，直到 **没法删**

考虑对每个结点维护一个 **物品队列**

由于每个结点在 **子树加** 操作中 作为整体存在，即 **结点内的物品权值均增加相同的值**

于是结点内 **物品权值顺序不变**，按照 **输入顺序** 插入队列即可使其 **权值有序**

然后路经询问想到 **树剖 + 线段树** 维护

对于每个结点，钦定其 **当前权值最小** 的物品权值 **作为结点权值**，线段树维护

寻找 **最好的物品** 即求 **权值最小** 且 **所在结点编号最小** 的点

**子树加** 在 $Dfn$ 序上可以转化为 **区间加**

**删除物品** 的操作即 **从结点的物品队列中弹出队首**，获取 **新的队首**

于是显然我们线段树需要支持 **单点修改**，**区间加**，**区间最小值**

按照上面思路维护即可，需要注意 **物品权值相等时** 要去维护 **结点编号最小** 的点

> 细节就上面那个，卡了老半天，感觉 $CF$ 这题 **数据有点水**
>
>  ```cpp
>  Input : 
>  5 5 4
>  1 2
>  2 3
>  3 4
>  4 5
>  4 5 1 4 3 
>  2 4 3
>  1 2 5 5
>  1 2 2 2
>  1 5 3 5
>  
>  Output :
>  4 1 5 2 4 
>  0 
>  0 
>  ```
>

```cpp
#include <bits/stdc++.h>

const int MAXN = 100005;
const long long INF  = 1ull << 62;

using namespace std;

int N, P, K;

struct Edge {
	int to, nxt;
} E[MAXN << 1];

int F[MAXN], H[MAXN], C[MAXN], tot;

inline void Add_Edge (const int u, const int v) {
	E[++ tot] = {v, H[u]}, H[u] = tot;
	E[++ tot] = {u, H[v]}, H[v] = tot;
}

namespace Tree_Cut {
	int Siz[MAXN], Son[MAXN], Top[MAXN], Dep[MAXN];
	int Ldf[MAXN], Rdf[MAXN], Idf[MAXN], Cnt;
	
	inline void DFS1 (const int x, const int f) {
		Siz[x] = 1, F[x] = f, Dep[x] = Dep[f] + 1;
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != f)
				DFS1 (E[i].to, x), Siz[x] += Siz[E[i].to], Siz[E[i].to] > Siz[Son[x]] ? Son[x] = E[i].to : Son[x];
	}
	
	inline void DFS2 (const int x, const int top) {
		Ldf[x] = ++ Cnt, Idf[Cnt] = x, Top[x] = top;
		if (Son[x]) DFS2 (Son[x], top);
		for (int i = H[x]; i; i = E[i].nxt)
			if (E[i].to != F[x] && E[i].to != Son[x])
				DFS2 (E[i].to, E[i].to);
		Rdf[x] = Cnt;
	}
}

queue <long long> Q[MAXN];

namespace SegTree {
	
	using namespace Tree_Cut;
	
	struct Node {
		int L, R;
		long long Min, Add;
		int Pos;
		
		inline bool operator < (const Node &a) const {
			return Min == a.Min ? Idf[Pos] < Idf[a.Pos] : Min < a.Min;
		}
	} T[MAXN << 2];
	
	#define LC (x << 1)
	#define RC (x << 1 | 1)
	#define M ((T[x].L + T[x].R) >> 1)
	
	inline void Maintain (const int x) {
		T[x].Min = min (T[LC].Min, T[RC].Min) + T[x].Add;
		if (T[LC].Min == T[RC].Min) T[x].Pos = Ldf[min (Idf[T[LC].Pos], Idf[T[RC].Pos])];
		else T[LC].Min < T[RC].Min ? T[x].Pos = T[LC].Pos : T[x].Pos = T[RC].Pos;
	}
	
	inline void Build (const int L, const int R, const int x = 1) {
		T[x].L = L, T[x].R = R;
		if (L == R) return T[x].Min = Q[L].front (), T[x].Pos = L, void ();
		Build (L, M, LC), Build (M + 1, R, RC), Maintain (x);
	}
	
	inline void Add (const int L, const int R, const int v, const int x = 1) {
		if (L >  T[x].R || T[x].L >  R) return ;
		if (L <= T[x].L && T[x].R <= R) return T[x].Add += v, T[x].Min += v, void ();
		Add (L, R, v, LC), Add (L, R, v, RC), Maintain (x);
	}
	
	inline void Val (const int p, const long long v, const int x = 1) {
		if (T[x].L == T[x].R) return T[x].Min = v + T[x].Add, void ();
		if (p <= M) Val (p, v, LC);
		else Val (p, v, RC);
		Maintain (x);
	}
	
	inline Node Min (const int L, const int R, const int x = 1) {
		if (L >  T[x].R || T[x].L >  R) return {L, R, INF, 0, 0};
		if (L <= T[x].L && T[x].R <= R) return T[x];
		Node l = Min (L, R, LC), r = Min (L, R, RC);
		if (l.Min < r.Min) return l.Min += T[x].Add, l;
		else return r.Min += T[x].Add, r;
	}
}

struct Answer {
	long long Pos;
	long long Val;
	
	inline bool operator < (const Answer &a) const {
		return Val == a.Val ? C[Pos] < C[a.Pos] : Val < a.Val;
	}
};

vector <Answer> Ans;

inline void Query (int u, int v, const int k) {
	using namespace Tree_Cut;
	
	int uu = u, vv = v;
	
	if (k == 0) return ;
	
	SegTree::Node Min = {0, 0, INF, 0, 0};
	
	while (Top[u] != Top[v]) {
		if (Dep[Top[u]] > Dep[Top[v]]) Min = min (Min, SegTree::Min (Ldf[Top[u]], Ldf[u])), u = F[Top[u]];
		else Min = min (Min, SegTree::Min (Ldf[Top[v]], Ldf[v])), v = F[Top[v]];
	}
	
	Min = min (Min, SegTree::Min (min (Ldf[u], Ldf[v]), max (Ldf[u], Ldf[v])));
	
	if (Min.Min >= (INF >> 1)) return ;
	
	Ans.push_back ({Q[Min.Pos].front (), Min.Min});
	
	Q[Min.Pos].pop (), SegTree::Val (Min.Pos, Q[Min.Pos].front ());
	
	Query (uu, vv, k - 1);
}

int u, v;
int Opt, x;

int main () {
	
	ios::sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	
	cin >> N >> P >> K;
	
	for (int i = 2; i <= N; ++ i) cin >> u >> v, Add_Edge (u, v);
	
	Tree_Cut::DFS1 (1, 0), Tree_Cut::DFS2 (1, 1);
	
	Tree_Cut::Idf[0] = N + 1;
	
	for (int i = 1; i <= P; ++ i) cin >> C[i], Q[Tree_Cut::Ldf[C[i]]].push (i);
	
	for (int i = 1; i <= N; ++ i) Q[i].push (INF);
	
	SegTree::Build (1, N);
	
	for (int i = 1; i <= K; ++ i) {
		cin >> Opt >> u >> v;
		if (Opt == 1) {
			Ans.clear (), cin >> x, Query (u, v, x);
			cout << Ans.size () << ' ', sort (Ans.begin (), Ans.end ());
			for (auto p : Ans) cout << p.Pos << ' ';
			cout << '\n';
		} else SegTree::Add (Tree_Cut::Ldf[u], Tree_Cut::Rdf[u], v);
	}
	
	return 0;
}
```
