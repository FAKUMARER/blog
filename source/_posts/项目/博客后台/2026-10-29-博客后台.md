## 基于 Github Pages 的静态博客后台

#### 项目简介

如题，一个 Web 端的博客后台

适用于想使用 Github Pages，且 Hexo 架构部署静态博客的用户

#### 项目特点

- 可视化后台，快速上手
- 一键初始化 Hexo 和主题
- 基本功能支持，博文分类，标签，摘要，加密，定时发布等
- 便捷的博文管理，左侧文件栏按分类整理博文，支持搜索
- 本地化编辑，自动保存，按需上传
- 与 Typora 相同的渲染规则，本地效果和博文展示效果几乎无差异
- 自动迁移外链，博文中的本地链接和外部链接在导入时自动下载并统一上传至仓库，防止失效
